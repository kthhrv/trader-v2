# Plan: Market Data Explorer (Reflex UI)

**Objective:** Add a "Market Explorer" tab to visualize the local `historical_candles` database. This validates that the `market-streamer` is working and provides a quick way to check market structure without opening the IG app.

## 1. UI Layout
- **Header:**
    - Dropdown: `[Select Market]` (Populated from `MARKET_CONFIGS`).
    - Toggle Group: `[1m] [5m] [15m] [1d]`.
- **Main View:**
    - **Candlestick Chart:** Interactive Plotly graph showing Open/High/Low/Close.
    - **Indicators (Bonus):** Overlay EMA20 if feasible.
- **Footer:**
    - Data Grid: Recent rows (Timestamp, Close, Volume).

## 2. Backend Logic (Reflex State)
- **`MarketState` Class:**
    - `selected_epic`: str
    - `selected_resolution`: str
    - `candles`: List[dict]
- **Query:**
    - `SELECT * FROM historical_candles WHERE symbol=? AND resolution=? ORDER BY timestamp DESC LIMIT 500`
    - Convert to Pandas DataFrame -> Plotly Figure.

## 3. Dependencies
- Ensure `plotly` is installed in the Dashboard environment.
- Reuse `app/database/models.py` to access the DB.

## Implementation Steps

### Phase 1: The Query
1.  Update `dashboard/rxconfig.py` or state to access `trader.db`.
2.  Implement `get_candles(epic, resolution)` function.

### Phase 2: The Chart
3.  Create `dashboard/components/chart.py`.
4.  Use `rx.plotly` to render a candlestick figure.

### Phase 3: The Page
5.  Create `dashboard/pages/market.py`.
6.  Wire up the Dropdown and Buttons to trigger the query.

## Success Criteria
- Selecting "FTSE" and "1m" shows the candles generated by the streamer.
- Real-time updates? (Optional: Poll every 60s).
